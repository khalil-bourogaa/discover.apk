DISCOVER — updated cinematic travel experience

INSTALL
1. Open your GitHub repository.
2. Upload/replace index.html, style.css and script.js.
3. Commit to main and wait for GitHub Pages to publish.
4. Hard-refresh the website (Ctrl+Shift+R).

APP / APK (PWA)
- Upload ALL files incl. manifest.json, sw.js and the icons/ folder. Site then installs as an app (Chrome: menu > Install app).
- For a real .apk: go to pwabuilder.com, paste your GitHub Pages URL, choose Android > Download package (APK/AAB).
